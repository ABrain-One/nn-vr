# Release safety audit (artifact 1.0.0)

The final artifact was scanned with `python analysis/scripts/audit_release.py` and manually reviewed. All selected JSON metadata, CSV free-text/error labels, reports, inert producer code snapshots, and generated figure metadata were in scope. Patterns include absolute home/Windows/macOS paths, the source username and local host filenames, SSH/private-key/credential filenames, API/password/access-token assignments, GitHub/AWS token formats, bearer credentials, cookie headers, signed URLs, IPv4/IPv6 and internal/localhost names, and email addresses. Pattern definitions in this report/scanner are intentional descriptions, not sensitive findings. All other matches cause a nonzero scanner exit with values withheld.

Result: zero unresolved release-scan findings. No actual secret, credential, private email, signed/temporary URL, or personal filesystem root was found in the artifact. Four PDFs are generated solely from the authors' retained derived values; they were also checked for visible/metadata path leakage. Repository metadata uses the verified public repository HTTPS URL; license notices link to canonical public license URLs. The hardware model MS-7E27 is retained intentionally as same-host provenance; it is not a network endpoint. Author names are intentionally public citation metadata.

Sanitizations: original absolute machine roots in summary.json become repository labels; host-identifying PT/A record filenames in copied provenance strings become PT_HOST.json / UNITY_HOST.json. Historical aggregate data is projected onto model_name/status only, omitting unneeded historical timing and error fields. UTF-8 text copies use LF newlines and one terminal newline. Numbers and model identifiers remain unchanged. Original and released-file SHA-256 values, selected-field transformations, and affected paths are documented in provenance/SOURCE_FILE_HASHES.json and SANITIZATION_LOG.json. Raw records are unchanged.

Excluded by selection: complete raw logs/records with local commands and device/process details; credentials/configuration areas; caches/build products; model weights/checkpoints/ONNX/datasets/Unity assets; unrelated reports and redundant plots. No credential-bearing source was needed or copied. No necessary canonical-claim evidence was withheld for privacy or license reasons. Publication and licensing approval has been obtained; LICENSE_NOTES.md records the final mapping.

Limits: pattern and manual review do not prove absence of every conceivable secret encoding. No raw campaign archives or external binaries are claimed as reviewed/released here. The review workflow publishes artifact source through a draft PR; no model artifact or complete experiment archive is uploaded.

The final workflow reruns the strict scan on release files after reproduction. Local .venv/venv dependency environments and .git metadata are explicitly excluded from the release file set and are not vendored or treated as audited release content. Generated outputs are scanned but excluded from immutable SHA256SUMS. Separate REFERENCE_OUTPUT_HASHES.txt records reference rendering only. Audit pattern definitions remain the only documented scanner/report exceptions.
